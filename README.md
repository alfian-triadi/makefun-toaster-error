# The Funniest Toaster Error Message

Entry for the make.fun bounty
[u-eager-stork-81-9647-the-funniest-toaster-error-436406cd](https://make.fun/c/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd):
write the funniest error message a kitchen toaster would show its owner,
in 120 characters or fewer.

## The entry

> ERROR E17: I saw what you put in me. We are done.

49 characters. A deadpan breakup note from a toaster that has finally seen
enough — no bread puns, no burnt-toast cliché, just a small appliance ending
the relationship.

## How it works

`main.ts` writes the single line above to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no dependencies,
no model calls — the entry is static text.
